KeyBPM Detector — установка на Windows
=======================================

1. Скопируй папку «KeyBPM Detector.vst3» в
   C:\Program Files\Common Files\VST3

   Если на диске C: мало места — положи её в любую папку, например E:\VST3,
   и добавь эту папку в FL Studio: Options → Manage plugins → Plugin search paths.

2. В FL Studio: Options → Manage plugins → Find installed plugins (Start scan).

3. Повесь «KeyBPM Detector» на канал микшера:
   - на Master — чтобы определить тональность и темп всего, что играет;
   - на отдельный канал — чтобы анализировать только сэмпл или бит.

4. Включи воспроизведение. Темп появится через ~5 секунд,
   тональность — через ~10 секунд. Чем дольше играет, тем точнее.

Ещё можно просто перетащить аудиофайл (wav, mp3, flac, ogg, aiff) прямо в окно
плагина или нажать «Открыть файл» — он проанализирует файл целиком за пару секунд.

Кнопки:
  Сброс       — начать анализ заново (нажимай, когда включаешь другой трек)
  Заморозить  — зафиксировать результат
  Открыть файл — выбрать аудиофайл

«KeyBPM Detector.exe» — то же самое отдельной программой, без FL Studio:
открой и перетащи в окно трек.
